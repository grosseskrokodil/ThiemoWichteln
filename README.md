# ThiemoWichteln

Eigenständiges Wichtelprojekt. Das Projekt startet als leeres Grundgerüst.

## Geplanter Zweck

Teilnehmer verwalten, Wichtelzuordnungen auslosen und die Ergebnisse anzeigen.
Die genaue Umsetzung wird im nächsten Schritt festgelegt.

## Lokal arbeiten

Dieser Ordner enthält die lokale Arbeitskopie. Änderungen werden mit Git
versioniert und können nach der Verbindung mit GitHub hochgeladen werden.

## Aktueller Stand

Noch keine Anwendung, Teilnehmerdaten oder Auslosung vorhanden.
